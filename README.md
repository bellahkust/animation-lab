# Animation Lab

An interactive playground for exploring web animation patterns and UI motion.

**Live site:** [bellahkust.github.io/animation-lab](https://bellahkust.github.io/animation-lab/)

## What is inside

Animation Lab collects small, reusable motion ideas that can be adapted to real websites:

- Hover transitions and lifted cards
- Keyframe bounce and click feedback
- Pointer-following and drag interactions
- Scroll reveal and progress animations
- SVG path drawing
- Animated gradients and shimmer loading states
- 3D perspective tilt and parallax layers
- Tooltips, ripples, toast feedback, and glitch text
- Animated buttons, navigation links, cards, tabs, and text patterns

Each experiment includes a short Chinese instruction that can be copied and reused when asking for an animation implementation.

## Built with

- HTML
- CSS animations and transitions
- Vanilla JavaScript
- SVG
- Intersection Observer and pointer events

No framework or build step is required.

## Run locally

Open `index.html` in a browser, or serve the folder with any local static server.

The published site uses `index.html` as its GitHub Pages entry point.

## Project structure

```text
index.html   Main playground page
styles.css   Layout, visual styling, and animation definitions
```
